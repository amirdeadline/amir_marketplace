# palo-kb-add

Ingest Markdown into `palo-alto-knowledge-base/` (analyze, dedupe/MERGE, write topics, update indexes),
including lean writer-pool / topic-queue waves.

## Invoke

| Tool | How |
|---|---|
| Claude Code / Cursor | `/palo-kb-add <path-or-topic>` or "add this to the KB" |

```powershell
powershell -File <marketplace>/scripts/install-user-skills.ps1 -Skills palo-kb-add
```
